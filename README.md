# RDKit-Cheminformatics-Course

A comprehensive hands-on RDKit course featuring 29 Jupyter notebooks covering core cheminformatics concepts, molecular analysis, 3D modeling, reaction workflows, and practical applications in drug discovery.

## 📖 Course Overview

# This repository provides a step-by-step introduction to RDKit, one of the most widely used open-source cheminformatics libraries. The notebooks are designed for students, researchers, medicinal chemists, and data scientists interested in computational chemistry and drug discovery.

Each notebook includes:
- ✅ Conceptual explanation
- ✅ Hands-on RDKit implementation
- ✅ Practical examples
- ✅ Visualizations
- ✅ Real-world applications
